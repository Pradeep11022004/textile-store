Textile Store Full Stack Team Project

## Project Overview

A full-stack web application for browsing textile products, viewing product details, managing user accounts, and placing orders.

## Technology Stack

- Frontend: React + Vite
- Backend: Java, Spring Boot
- Database: MySQL
- Tools: Git, GitHub, Postman

## Frontend Setup

This project uses React with Vite.

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

## Project Features

- Product listing and product details
- User registration and login
- Product stock and pricing
- Cart and order management
- Admin and customer roles

## Team Project

This project is being developed collaboratively as a full-stack team project.
